How different are
two signals? Look at their shape in phase space.

Time-delay embedding turns each signal into a trajectory. CPST measures how far the test trajectory drifts from the reference on average; the percentile Hausdorff distance finds the largest local gap. Everything below runs in your browser.

03 / CPST

Change in Phase Space Topology: the average drift

For every test point, average its k nearest reference points into a centroid and measure the gap. CPST is the mean gap over the whole trajectory, so it responds to changes that are spread over the signal.

  1. Pick a test point sᵢ on the pink trajectory (slider below).
  2. Find its k nearest reference points (black dots) and average them into a centroid r̄ᵢ (white diamond).
  3. Measure the gap Eᵢ = ‖sᵢ − r̄ᵢ‖, the pink segment.
  4. Average all gaps: CPST = mean(Eᵢ).

CPST = 1/N Σ ‖ si − (1/k) Σj∈Nk(i) rj ‖

04 / Hausdorff

Percentile Hausdorff distance: the largest local gap

Every point looks for its nearest neighbour on the other trajectory, in both directions. The classical Hausdorff distance keeps the single worst gap; the percentile version keeps the q-th percentile, so one bad sample cannot decide the result.

06 / Code

Same algorithm in Python

The psdist package reproduces this page and the values reported in the PECT study. MIT licence.

# pip install -r requirements.txt
import psdist
from psdist.mock import make_pair

t, ref, test = make_pair("shape", severity=0.3)
psdist.cpst(ref, test, tau=8, m=3, k=5)        # 0.335
psdist.hausdorff(ref, test, tau=8, m=3, q=95)  # 0.418
